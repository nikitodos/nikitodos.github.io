# G. N. D'Aloisio — Personal Portfolio

Source code and assets for the personal portfolio of G. N. D'Aloisio, documenting research and design at the intersection of space engineering, astrophysics, and space architecture. 

Hosted via GitHub Pages: [nikitodos.github.io](https://nikitodos.github.io)

## Architecture & Design System

The website is developed using pure HTML5 and CSS3, operating with zero external dependencies or JavaScript frameworks to ensure maximum performance and longevity. The design language emphasizes academic rigor and engineering precision through a custom aesthetic.

* **Color Palette:** Custom CSS variables utilizing paper-like backgrounds (`--paper`, `#f0ede6`) and blueprint accents (`--blueprint`, `#0d2b52`) to emulate interactive technical schematics.
* **Typography:** Mixed typographic hierarchy pairing *EB Garamond* for narrative prose with *DM Mono* for technical data, specifications, and telemetry.
* **UI/UX Elements:**
    * Hardware-accelerated SVG fractal noise filter (`feTurbulence`) applied globally for visual texture.
    * Responsive CSS Grid and Flexbox architectures for project cards and publication lists.
    * Custom dynamic cursor mapped to interactive elements.

## Content Structure

1.  **Research & Reports:** Chronological repository of technical reports and academic publications, featuring detailed abstracts, venue data, and categorical tagging (e.g., *HyperLander*, *Ikarus* series, *KLT* thesis).
2.  **Projects:** Grid-based overview of hardware and conceptual projects, incorporating quick-reference technical specifications (`pc-specs`).
3.  **The Space Framework:** A dedicated, dark-themed breakdown of the long-range architectural concept for a post-OST interplanetary economy.
4.  **Collaborations:** Summary of relevant academic, research, and technical roles.

## Repository Layout

* `index.html`: The core single-page application and stylesheet.
* `content/`: Directory hosting all static assets, including project logos, vector marks, and downloadable PDF reports.
